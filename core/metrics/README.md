# core/metrics

키트의 효과를 숫자로 보이는 수집기. 로드맵 M2-6(CI 실패 분류)과 M4-1·M4-2에서 채운다.

수집하는 지표 (roadmap 1장)

| # | 지표 | 출처 |
| --- | --- | --- |
| 1 | 병합 후 발견된 누락 수 | 리뷰 파일 측정 칸 → MR 본문 "검증" 절 |
| 2 | 게이트 단계 MR 비율 | 플랜 상단 판정 → MR 본문 |
| 3 | CI 실패 원인 분류 | job 로그 규칙 분류 (테스트 · 포맷 · 인프라 · 타임아웃) |
| 4 | 판정 스크립트와 사람 판정의 불일치 수 | `harness judge` 출력과 플랜 판정 대조 |

예정 내용: `collect.py`(MR 본문·CI API에서 JSON 추출), `classify-ci.py`, `notify.py`(주간 요약 webhook 발송,
feelm Jira 일일 요약 발송 코드 이관).
