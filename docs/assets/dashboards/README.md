# 대시보드 스크린샷

루트 README에서 사용하는 화면 이미지다. 로컬 Grafana에서 목데이터로 촬영했다.

- `team-usage.png`·`collection-diagnostics.png`: 2026-10-26, #157 대시보드와 기본 라이트 테마. 로컬 전용 수집기에 키트 전송
  코드(`telemetry push`, v2 `send_records`)로 최근 7일(10/20~10/26) 목데이터를 넣고 `Last 7 days`로 찍었다. 근무 시간에 몰리고
  주말에 적은 사용량, 날짜별 hooks 개입이 보이도록 날짜·시간대를 나눠 만들었다.
- `task-evidence.png`: 2026-10-22 촬영본(다크 테마, 10/15~10/22). 작업 검증 기록은 프로젝트 확장이라 다시 찍지 않았다.
운영 서버, 실제 세션 로그, 실제 사용자 기록을 캡처하지 않았다.

| 파일 | 화면 | 데이터 |
| --- | --- | --- |
| `team-usage.png` | 공통 수집 v2 팀 사용량 | 7일간 가상 팀원 3명·도구 2종의 토큰(일별), 완료 응답, 예시 가격과 단가 미등록 모델 |
| `collection-diagnostics.png` | 수집·차단 진단 | 마지막 전송·24시간 전송 없음과 전송·읽기 오류(한 표), Claude 보호 규칙 개입(합계·차단·확인 요청)·종료 검증 사건 |

- 저장소 필터는 `readme-demo`, 사람 필터는 `demo-.*`로 고정했다.
- 가상 팀원은 `demo-alex`, `demo-jin`, `demo-min`, 작업은 `DEMO-140`~`DEMO-142`다.
- 예시 모델명과 단가는 설명용이다. 실제 모델 가격표나 성능 비교에 사용하지 않는다.
- 화면 제목에 `목데이터`를 표시했다. 실제 Grafana 패널·쿼리를 실행한 화면이며, 디자인 시안을 이미지로 만든 것이 아니다.
- 실행 시각에 따라 예시 날짜가 달라진다.
- 공통 사용량은 #140 작업 버전, 작업 근거는 프로젝트 확장이다. 기본 키트에 모두 포함된다는 의미가 아니다.

## 화면 구성 목업 (#156)

`mockup-*.png`는 실제 Grafana 화면이 아니라 **설계 목업**이다. 2026-10-26에 화면 구성을 합의하려고 Wanted Design System의
색·글꼴·모서리 규칙으로 만든 시안을 로컬 헤드리스 브라우저로 그렸다. 패널 쿼리를 실행하지 않았고 수치는 위와 같은 가상 팀원의
예시 값이다.

| 파일 | 화면 | 실제 반영 |
| --- | --- | --- |
| `mockup-team-usage.png` | 팀 사용량 | 사람별 사용 내역의 도구별 토큰 열, 카드 설명 |
| `mockup-collection-diagnostics.png` | 수집·차단 진단 | 카드 값 이름, 수집 상태·오류 표 통합, 최근 사건 표, Claude Code 내장 텔레메트리 행(펼친 모습) |
| `mockup-task-evidence.png` | 작업 검증 기록 | 프로젝트 확장. #156에서 반영하지 않음 |
| `mockup-team-usage-detail.png` | 팀 사용량 · 접힌 행 펼침 | 모델·토큰 상세와 가격 기준(패널 구성은 기존과 같음) |
| `mockup-collection-diagnostics-detail-1.png` | 수집·차단 진단 · 접힌 행 펼침 ① | 관측 지연, Claude hooks, 기존 원천 진단 |
| `mockup-collection-diagnostics-detail-2.png` | 수집·차단 진단 · 접힌 행 펼침 ② | Claude Code 내장(#156 추가), Codex 내장, 수집 범위·지표 정의 |

- Grafana에 반영한 것은 패널 구성·제목·배치·색이다. 상단 탭·배지·알림 박스·타임라인·글꼴 같은 겉모양은 Grafana 테마로
  만들 수 없어 실제 화면과 다르다.
- 펼친 상세 목업의 패널 제목·설명·열·폭은 실제 대시보드 JSON을 따르며, 값과 그래프 모양은 예시다.
- 목업의 Pretendard는 이 PC에 없어 Noto Sans KR로 그려졌다.
